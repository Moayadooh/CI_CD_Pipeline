Configure VM

Enable Nested Virtualization on the local machine by open PowerShell as Administrator:
Set-VMProcessor -VMName "Windows 11 dev environment" -ExposeVirtualizationExtensions $true

Verify if Nested Virtualization Enabled:
in the VM got to Task Manager - Performance - CPU and ensure "Virtualization" shows as "Enabled"

Step 2
Install Docker & Dockorize the App

Install Docker engine in the Windows server and local machine:
https://www.docker.com/

Create the .NET 10 Dockerfile to the root of .NET10 web app repository:
# Build stage
FROM mcr.microsoft.com/dotnet/sdk:10.0 AS build
WORKDIR /src
COPY ["MyWebApp.csproj", "./"]
RUN dotnet restore "MyWebApp.csproj"
COPY . .
RUN dotnet publish "MyWebApp.csproj" -c Release -o /app/publish

# Runtime stage
FROM mcr.microsoft.com/dotnet/aspnet:10.0 AS final
WORKDIR /app
COPY --from=build /app/publish .
ENTRYPOINT ["dotnet", "MyWebApp.dll"]

Step 3
Configure Jinkinsfile & CI/CD Pipeline

Install Jenkins and it's dependencies (refer to previous steps)

Configure OpenSSH Server:
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

Configure Jenkins to exxecute pipeline and access to Docker hub:

Install pulgins below via Manage Jenkins > Plugins > Available plugins, then restart Jenkins
- Docker Pipeline
- SSH Agent
- Credentials Binding

Configure Docker Hub Credentials
1 - In Jenkins, go to Manage Jenkins > Credentials > System > Global credentials (unrestricted).
2 - Click Add Credentials.
3 - Set Kind to Username with password.
4 - Enter your Docker Registry username and password (or access token).
5 - Set the ID strictly to dockerhub-creds to match your pipeline script, then save.

Configure VM SSH Credentials
1 - Before doing this, generate an SSH key pair on your Jenkins server using ssh-keygen. You must place the resulting public key (id_rsa.pub) into the C:\Users\vm_admin\.ssh\authorized_keys file on your Windows 11 VM to authorize the connection.
2 - Navigate back to Global credentials (unrestricted) and click Add Credentials.
3 - Set Kind to SSH Username with private key.
4 - Set the Username to your VM's login user (e.g., vm_admin).
5 - Under Private Key, click Enter directly, select Add, and paste the full contents of your Jenkins server's private key (id_rsa).
6 - Set the ID to vm-ssh-creds to match your pipeline script, then save.

create a Jenkinsfile to the root of .NET10 web app repository:
pipeline {
    agent any
    environment {
        // Define your local registry address (Change 5000 if your registry uses a different port)
        REGISTRY_URL = 'localhost:5000'
        IMAGE_NAME   = 'webapp'
        DOCKER_IMAGE = "${REGISTRY_URL}/${IMAGE_NAME}"
        
        VM_IP        = '192.168.100.124'
        VM_USER      = 'user'
    }
    stages {
        stage('Build & Push to Local Registry') {
            steps {
                script {
                    withEnv([
                        'DOCKER_CONTEXT=default',
                        'DOCKER_HOST=npipe:////./pipe/docker_engine',
                        'DOCKER_BUILDKIT=1',
                        'BUILDKIT_PROGRESS=plain'
                    ]) {
                        bat """
                        docker build -t %DOCKER_IMAGE%:latest .
                        docker push %DOCKER_IMAGE%:latest
                        """
                    }
                }
            }
        }
        stage('Deploy to VM') {
            steps {
                sshagent(['vm-ssh-creds']) {
                    bat """
                    ssh -o StrictHostKeyChecking=no ${VM_USER}@${VM_IP} "docker pull ${DOCKER_IMAGE}:latest && docker stop webapp || true && docker rm webapp || true && docker run -d -p 8080:8080 --name webapp ${DOCKER_IMAGE}:latest"
                    """
                }
            }
        }
    }
}
